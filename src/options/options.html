Permanent product rule

Creator Attribution Guarantee

If a creator sent you to a store, Comb leaves their attribution intact. This build has no affiliate ID, never rewrites a referral URL, never changes attribution cookies, and never opens a hidden commission link.

On-device data use

Privacy at a glance

Comb handles the current merchant hostname, coupon tokens, coupon controls/messages, and displayed payable amount/currency to run the test. The Comb developer receives none of that checkout data.

  • Coupon lists, trusted keys, feeds, and source settings stay in extension-local storage until you remove them.
  • The current merchant receives only the coupon token entered into its existing visible field.
  • An optional feed operator sees ordinary network metadata only after you enter its public HTTPS URL and approve the origin.
  • A safe compatibility report is saved only when you choose it; Comb never uploads the report.

Full public policy: github.com/djlacavera21/Comb/blob/main/docs/PRIVACY.md
